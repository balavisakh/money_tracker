# Money Tracker (Android)
Monthly income/expense tracking, SMS import (bank credit/debit alerts), EMI tracker.

Build APK:
- Android Studio: open this folder, Build > Build APK(s).
- Or push to GitHub: the "Build APK" Action produces app-debug.apk as a download.
- Or CLI with Android SDK installed: ./gradlew assembleDebug  -> app/build/outputs/apk/debug/
